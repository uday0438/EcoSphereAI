AI integration 03 / 08

Gemini Sustainability Coach 🤖

Powered by gemini-2.5-flash. Evaluates personal footprint prompts and returns localized Indian optimization guides.

🇮🇳
Localized Context
Recommends Indian transit systems (Delhi/Namma Metro) & local services (Sogo e-waste, solar panels).
🎛️
Security & Guardrails
Equipped with prompt-injection filters & text input limitations under 500 characters.
🪵
JSON schema
Express API enforces structured outputs for client-side card visualization.
Carbon Math 04 / 08

Real-Time Indian Simulator 📊

Custom calculation engine referencing localized Indian emission baselines vs the national average of 2.8 Tons CO₂/year.

🔌
Grid Electricity
Calibrated with India's heavy coal factor of 0.82 kg CO₂/kWh.
🚗
Transit Baselines
Cars (0.143 kg/km), Two-Wheelers (0.044 kg/km), CNG Auto-rickshaws (0.065 kg/km).
🍛
Diet Carbon
Reduces carbon from mutton/beef (4.5 kg/meal) down to Indian millets (0.3 kg/meal).

Interface APIs 07 / 08

Greeny Voice Assistant 🗣️

An interactive floating drawer enabling hands-free voice chats using browser-native APIs.

🎤
Speech-to-Text (STT)
Binds to webkitSpeechRecognition API for simple, hardware-free speech inputs.
🔊
Text-to-Speech (TTS)
Binds to SpeechSynthesisUtterance with a friendly, custom-pitched response speaker.
💬
System Context
Greeny is styled with system prompts detailing the Plastic Soup Partnership and VOC toxin warnings.
System Design 08 / 08

Technical Architecture 💻

A modern full-stack monorepo designed for serverless scalability and deployment.

📦
Frontend Stack
React 19, Vite, TailwindCSS v4, TypeScript, Lucide Icons, and Framer Motion.
🚀
Backend API
Node.js, Express, and @google/genai SDK calling gemini-2.5-flash.
☁️
Vercel Deployment
Single vercel.json routing frontend CDN to backend serverless functions at /api/*.
